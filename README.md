- 🛰️ I write C for applications on **NASA's core Flight System (cFS)** at GISTDA, Thailand's space agency.
- 📡 I build **drone Remote ID** systems: ESP32-S3 firmware that broadcasts drone identity, and a **React Native** app that scans for nearby drones.
- 🐧 I set up and run **Linux servers** and **Docker** as part of daily work.
